## 八、坑记录（本次新增）

| 坑 | 现象 | 修复 |
|---|---|---|
| Mac BSD sed -i 语法 | `sed -i "s/\r$//"` 报 invalid command code e | Mac 的 -i 需要空参数 `-i ''`；Python 兼容 CRLF 可跳过转换 |
| 旧 evidence_badge 同名覆盖 | 新徽标函数被文件后部的旧定义覆盖（🅰 一手 出现在 🔍 位置） | 旧函数改名 source_evidence_badge |
| 旧视图 evidence 是 str | evidence_detail 对 str 调 .get() 崩（AttributeError） | isinstance(ev, dict) 守卫（同 confidence float 处理） |
| _render_evidence_details 未 attach | 详情区全部显示"原文缺失" | 函数内先 attach_dimensions |
| gate 裸 % 在行情词典 | 所有含 % 的行被当行情类放行（假简报 3.5% 漏检） | 行情类只认强信号词（昨收/收盘/缓存价/涨跌幅） |
| 占位锚点 quote 空串 | `IS NULL` 查询显示 quote 全非空，实际 1166 条空串 | 统计口径区分 NULL vs 空串 |
| heredoc 中文脚本经 bash | 行内 `>` 等被重定向/解析 | 检查脚本 scp 到 Mac 再执行，不走 heredoc |
