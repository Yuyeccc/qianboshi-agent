## 三、方案（最小刀）

### A. portfolio.json 补流水 + updated
- history 追加一条：
  ```json
  {"date": "2026-08-05", "action": "buy", "code": "159992",
   "amount": 989.01, "shares": 1100, "nav": 0.8991}
  ```
  （amount=1100×0.8991=989.01，与 closed_positions.cost 一致）
- `updated`: "2026-08-27" → "2026-09-01"（账本修复时间）
- total_cost/holdings/closed_positions 不动

### B. 一致性校验脚本 scripts/ledger_verify.py
```bash
python scripts/ledger_verify.py   # 退出码 0=通过
```
校验 5 项：
1. history 买入总额 == gross_invested（Σ closed.cost + Σ holdings.buy_amount）
2. history 卖出总额 == Σ closed.proceeds
3. 每个 closed_position 的卖出流水完整（sell 条数与 sell_dates/sell_date 匹配）
4. 每个 holdings 的买入流水存在
5. 每股 code 的买-卖流水金额与 closed/holdings 对账（卖<=买 不出现负数仓位）
