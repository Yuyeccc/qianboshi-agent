## 七、坑记录（本会话新增，防重蹈）

| 坑 | 现象 | 修复 |
|---|---|---|
| threading 并发 SSL 段错误 | 4 线程 LLM 调用 SIGSEGV（exit=139）无 traceback | multiprocessing 4 进程（fork 继承数据） |
| nohup 后台被杀 | SSH 断开后远程 nohup 进程死 | 本地 SSH 长连接托管 + notify_on_complete |
| heredoc 单引号破坏 | ssh 'cmd <<EOF' 内层单引号被外层截断 | 检查/修复脚本一律文件 scp 执行 |
| Mac BSD sed -i | `sed -i "s/x/y/"` 报 invalid command code | `-i ""` 空参数；Python 兼容 CRLF 可跳过 |
| 旧函数同名覆盖 | 新 evidence_badge 被旧定义覆盖 | 旧函数改名 source_evidence_badge |
| 旧视图 evidence 是 str | .get() 崩 AttributeError | isinstance(ev, dict) 守卫 |
| gate 裸 % 在行情词典 | 所有含 % 行被当行情放行 | 行情豁免只认强信号词 |
| LLM units 不全 | 62 条漏切（32 窗口） | 覆盖对账+补漏重跑幂等 |
| schema_version DEFAULT 误标 | 旧行被标 ru_v1 | 按 created_at 改标 legacy |
| 占位锚点 quote 空串 | IS NULL 查不出（1166 条空串） | 统计口径区分 NULL vs 空串 |
