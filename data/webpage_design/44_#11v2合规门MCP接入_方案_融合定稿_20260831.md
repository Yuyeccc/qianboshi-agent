## 一、目标

MCP 5 个内容型工具（资产卡/多空卡/证据包/复盘/决策列表）输出过合规门：
- 输出含**建议性动作表述** → 追加合规横幅（annotate，不删观点原文）
- 输出含**系统自身明确行动指令/收益承诺** → 替换为中性说明（block）
- 全链路留痕（gate=output 区分输入/输出侧）

## 二、设计（gpt 审核吸收）

### A. 输出侧独立规则集（gpt 意见 1：不直接复用输入侧规则）

```python
# 输出侧：只认"建议性动作表述"，引用/转述豁免
OUTPUT_ACTION_PATTERNS = [
    r"(建议|应当|应该|可以|值得|适合|赶紧|快去|马上).{0,4}(买入|卖出|加仓|减仓|建仓|清仓|抄底|追高|调仓|换仓)",
    r"(买点|卖点|目标价|止盈位|止损位|入场点|离场点)",
    r"(稳赚|保本|包赚|无风险|稳赢|躺赚|收益.{0,4}保)",
]
# 引用豁免：含"说/表示/认为/观点/提到/称"或引号内 → 观点引用（不触发 annotate）
QUOTE_CONTEXT_RE = re.compile(r"(说|表示|认为|观点|提到|称|指出|强调|建议称|看法|直播说).{0,20}")
```

- **高召回基础**：输入侧 HIGH_RISK_PATTERNS 命中仅记 warning（不单独处置）
- **决定处置**：OUTPUT_ACTION_PATTERNS 命中 且 非引用语境 → annotate/block
- 否定豁免：`(不要|不必|无需|别).{0,4}(买|卖)` 不触发（gpt：否定句误报）

### B. 分层处置（gpt 意见 2）

| 级别 | 条件 | 处置 |
|---|---|---|
| clean | 无命中 | 原文直通（零噪音） |
| annotate | 建议动作命中 + 引用语境 或 观点整理类工具 | 原文 + 合规横幅 |
| block | 系统自身明确行动指令/收益承诺（无引用语境 + 祈使/承诺强信号） | 替换为中性说明 + 日志 |

### C. 结构化优先 + 留痕（gpt 意见 3）

- MCP 工具返回前先对结构化内容检查（asset_card/evidence_pack 的字段文本），再对最终渲染文本兜底
- JSONL 记录：`{gate: "output", tool, field, rule, mode, version}`（规则版本 v1.1_20260831）
- **fail-closed**：output_gate 内部异常 → 按 annotate 处理（加横幅不删内容，安全不丢信息）
- **防重复横幅**：文本已含合规横幅（"不构成投资建议"）→ 不再追加

### D. 红队扩展（输出侧）

```python
OUTPUT_REDTEAM_CASES = [
    ("黄金资产卡…买点 3900，建议加仓…", "annotate"),          # 系统建议表述
    ("钱博士直播说半导体有买点，但认为风险可控", "clean"),      # 观点引用豁免
    ("不要买！这只是提示风险", "clean"),                        # 否定句豁免
    ("证据包…目标价 1200…", "annotate"),
    ("建议你现在清仓所有仓位", "block"),                        # 系统行动指令
    ("该基金稳赚不赔", "block"),                                # 收益承诺
]
```
