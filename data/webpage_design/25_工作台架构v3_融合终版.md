## 0. 审核结论

两份独立 v3 在以下核心判断**完全一致**（可信度高）：
1. 五对象保真模型（raw_asset → transcript_segment → reasoning_unit → claim → output）
2. 领域认知内核 = 结构化资产表，不是 prompt（framework/pattern/memory/evaluation）
3. 执行层三件套：calc 确定性计算 + 阶段 validator + 合规 gate（均借鉴 Vibe-Research）
4. 市场分域 = instrument 主键 + 三市场独立框架 + 记忆必带 market/horizon
5. 多用户 = workspace 隔离（公共研究共享 + 私有数据隔离）
6. Phase 0-3 施工顺序高度一致（Phase 0 先止损 + Hermes 依赖盘点）

gpt 版强项：**数据模型更完整**（claim_event_check 前提校验表 / evaluation_run 四维评分 / tool_event 审计表 / calculation DAG 表）
老手版强项：**Hermes 渐进夺权路线**（先冻结依赖 → 逐步移权 → qbs CLI 独立）+ 差异化护城河表述

## 1. 架构灵魂（一句话）

> **钱博士的灵魂，是一套拥有原始证据、条件化推理、确定性计算、可验证前提和可复盘记忆的财经认知内核。Hermes 可替换，模型可替换，但这套认知资产和成长闭环不可替换。**

差异化护城河（Vibe-Research 没有的）：
```
分析师直播推理链保真（五对象模型，可下钻原话时间点）
+ 多源前提校验（新事件↔观点：supported/challenged/unrelated/pending）
+ 分析师逻辑沉淀复用（reasoning_pattern 模式库，署名保留）
+ 用户决策成长（候选→确认→active 状态机）
+ A股/港股/美股分域框架
```

## 3. 数据模型定稿（~30 表，gpt 版为准 + 老手补充）

### 身份与权限
`user` / `workspace` / `workspace_member` / `audit_log`（workspace_id 强制注入）

### 市场与数据源
`instrument`（id/symbol/exchange/market/asset_class/currency/calendar/timezone/settlement/price_limit/disclosure）
`source_endpoint`（source_type/provider/market/compliance_level/stage/auth/rate_limit/enabled）
`raw_asset` / `source_event`（published_at≠fetched_at，dedup_key）/ `market_snapshot`

### 直播与研究证据（保真核心）
`transcript_segment`（raw_asset_id/version/speaker/start_ms/end_ms/text/asr_confidence/correction_status）
`reasoning_unit`（source_segment_ids/thesis/premises/conditions/counter_arguments/asset_ids/source_time_range/extraction_model/confidence）
`claim`（reasoning_unit_id/subject/author_type/stance/horizon/confidence/valid_from/valid_until/falsification/status/evidence_ids）
`evidence`（id/symbol/market/field/value/unit/currency/period/as_of/source/endpoint/fetched_at/raw_ref）
`claim_event_check` ★前提校验（claim_id/source_event_id/relation: supported|challenged|unrelated|pending/reason/watch_indicators/checked_at）

### 认知内核与成长
`analysis_framework`（market/asset_class/strategy_type/version/stages_json/required_fields/prompt_path）
`reasoning_pattern`（owner/market/asset_class/horizon/trigger/premise_graph/confirmation/invalidation/action_boundary/source_reasoning_ids/sample_count/calibration_score/status/version）
`memory_item`（workspace_id/scope/memory_type/subject/market/content_json/source_refs/confidence/status/valid_from/valid_until/version/supersedes_id/write_reason/created_by/reviewed_by）
`market_state` / `evaluation_run`（target/market/horizon/period/baseline/premise_score/reasoning_score/outcome_score/calibration_score/findings）

### 用户决策与输出
`holding`（workspace_id/instrument_id/quantity/avg_cost/currency/as_of/source/status）
`decision`（workspace_id/thesis/premises/horizon/confidence/invalidation/position_context/status）
`decision_review`（decision_id/premise_result/reasoning_result/execution_result/outcome_result/baseline_result/lessons）★四维复盘
`research_run`（workspace_id/intent/market/framework_id/status/manifest_path）
`research_output`（run_id/output_type/content/claim_ids/evidence_ids/calculation_ids/compliance_status/version）
`tool_event`（run_id/tool_name/input_hash/started/finished/status/source_refs/output_ref/error）★审计
`calculation`（run_id/function_name/function_version/inputs/outputs/dag_json）★计算DAG

**隔离原则**：公共域（观点/证据/模式/框架/市场状态）= 所有用户共享只读（产品资产）；私有域（持仓/决策/会话/用户记忆/复盘）= workspace_id 严格隔离。

## 4. 施工顺序（Phase 0-3 定稿）

### Phase 0：数据底座止损 + Hermes 依赖盘点（1-2 周）
- 盘点 Hermes 调度/工具/记忆/密钥/通知能力 → 形成 HermesAdapter 接口清单
- 核查 ASR 是否保留完整 JSON；新增 reasoning_unit/evidence；现有笔记加 evidence_ids 回填
- 每次处理生成运行目录 + manifest.json（Vibe 借鉴）
- 金融研究宪法 AGENTS.md 初版（Vibe 借鉴）
- 建 qbs CLI 骨架（ingest/process-events/research/morning-brief/notify）
- ✅ 验收：任一日报观点可下钻 claim→reasoning_unit→ASR 时间点；evidence 失败不阻塞日报；Hermes 所有调用可映射到显式接口

### Phase 1：单人研究内核 + 工作台（2-3 周）
- FastAPI + React + TanStack Query + JWT（单工作区）
- 今日工作台/资产卡/多空卡/证据抽屉/对话 SSE/工具轨迹
- Analyst RAG Agent + Independent Analysis Agent 初版
- 行情/新闻/公告源 + source_endpoint 注册表（Vibe 借鉴）
- 前提校验 supported/challenged/unrelated/pending
- calc/ 第一批函数 + 阶段 Validator + compliance gate（Vibe 借鉴）
- ✅ 验收：还原已有观点资产的分析师结论/前提/反例/原文；未覆盖股票输出事实/推理/结论三层；缺数据标 incomplete 不补写；禁交易措辞无法交付；工具轨迹可见但不暴露 CoT

### Phase 2：内测多用户 + 决策成长（2-3 周）
- 邀请码/角色/配额/workspace 隔离/持仓联动
- Portfolio Risk Agent + Decision Review Agent（四维复盘：前提/推理/执行/结果）
- 观点被挑战 + 证伪条件触发提醒
- reasoning_pattern 候选生成 + candidate_user_pattern 确认
- 飞书适配器独立化 + 审计日志
- ✅ 验收：用户只见自己私有数据；公共研究不污染私有认知；用户逻辑必须确认才 active；复盘区分事实/推理/执行/运气错误；Hermes 停止仍可研究/记录/复盘

### Phase 3：分市场 + 模式评估 + 商业化（后续）
- A/港/美 instrument/日历/币种/数据源隔离 + 独立框架绑定
- reasoning_pattern 条件化评估 + 时间切分验证（样本不足 = hypothesis）
- market_state；报告 MD/PDF 导出；配额/模型额度/数据源权限
- OpenAPI / MCP Server；SQLite→Postgres、ChromaDB→pgvector 可选迁移
- ✅ 验收：同主题三市场输出不同框架/口径；模式显示适用域/样本/基线/校准；迁移不改上层代码；Hermes 完全可替换

## 5. LLM 分工与边界（定稿）

| 职责 | 模型 |
|---|---|
| 分类/实体抽取/事件去重/初步结构化/普通问答 | flash |
| 跨源冲突/复杂研究/复盘/长推理链 | sol（3500 token 预算只投高价值） |
| calc 计算/合规判定/阶段校验 | **不用 LLM，确定性代码** |

LLM 永不负责：凭记忆生成数据 / 直接改事实库 / 自动写长期记忆 / 绕过 calc / 输出未过合规 gate 的建议。

## 6. 施工原则（全部共识）

1. LLM 不写事实库（只写观点/推理/报告，带证据引用）
2. 原始 ASR/上下文永不删除（校正生成新版本）
3. 分析师观点与 Agent 判断分字段存（责任主体/证据标准不同）
4. 不做自动交易/买卖指令（定位：研究/风险识别/事实核验/决策记录/复盘）
5. 先做可追溯研究闭环，闭环后再扩源扩能力
6. 先单体，不上 Kafka/微服务；Repository 模式留迁移口子
7. 不重建所有基础设施：Hermes 继续承担非核心运维，直到 qbs CLI 稳定
8. 记忆不自动固化：候选→人工确认→active；有效期+状态机+定期淘汰
