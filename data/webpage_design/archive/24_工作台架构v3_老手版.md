## 0. 一句话灵魂

> **数据是资产，认知是灵魂，Hermes 是工具。**
> 分析师直播的推理链永不丢失（保真）；分析师的逻辑可沉淀复用（模式库）；
> Agent 慢慢懂你的逻辑（记忆+确认）；A股/港股/美股各有一套框架（分域）；
> Hermes 从"房东"降级为"可选执行器"。

## 2. 与 Vibe-Research 的取舍（抄什么 / 坚持什么）

### 抄它的（已验证的落地设计）

| 设计 | 抄法 | 对我们的价值 |
|---|---|---|
| **金融研究宪法**（AGENTS.md） | 写一份 qianboshi 版的领域纪律文件（禁凭记忆出数/计算走calc/不荐股/五问Gate/裁决点） | 把散在 prompt 里的纪律固化成最高优先级文档 |
| **六阶段 SOP + validator** | profile→financials→estimates→valuation→risk→report，每阶段校验产物 | "分析框架"从 prompt 软要求变成编排器硬执行 |
| **确定性计算库 calc/** | 建 calc 包：估值/比率/情景函数，LLM 只选输入解释输出 | 防 LLM 胡说数字，数字可复核 |
| **合规 gate** | 报告命中"建仓/加仓/目标价/止损"→拒绝交付（含繁简/零宽/硬测试探针） | 付费产品的法律护城河 |
| **证据 JSON 字段标准** | id/symbol/market/field/value/unit/currency/period/as_of/source/endpoint/fetched_at/raw_ref | 证据可机器校验 |
| **运行磁盘契约** | 每次研究 = 唯一目录 + manifest/raw/evidence/calculations/events.jsonl/report | 过程可审计、可重放 |
| **数据端点注册表** | 端点 × market × 合规等级 × 阶段归属 的 registry.json | 市场分域在数据层完成 |

### 坚持我们的（Vibe-Research 没有的差异化）

| 差异化 | 设计 | 为什么是护城河 |
|---|---|---|
| **分析师直播推理链保真** | evidence_extractor：直播→推理单元→可下钻原文时间点 | 它有研报数据，但没有"真人分析师观点+推理链" |
| **分析师逻辑沉淀复用** | reasoning_pattern 模式库：从复盘正确的分析师逻辑提炼"条件→推理→边界"模板，署名保留 | 市面上没人做"从真实直播提炼可复用逻辑" |
| **学习用户交易逻辑** | 候选→确认→active 状态机；"观察到您6次决策有此倾向，是否设为规则" | 个性化是付费用户留存的根 |
| **多分析师对照** | 已有 debate_card，加"前提校验"（新事件↔观点：supported/challenged/pending） | 观点不是死的，会被新事实检验 |
| **A股/港股/美股分域** | 三套 market_framework + instrument 主键 + 记忆必带 market/horizon | Vibe 只深研 A 股，用户持仓横跨三市场 |

## 3. 数据模型定稿（表清单）

```
【公共研究域 shared】
instrument        标的（id/symbol/exchange/market/currency/asset_class/calendar/timezone/涨跌停规则）
source_event      消息事件（source/type/ts/entities/hash/raw_uri/reliability/published_at≠fetched_at）
transcript_segment ASR片段（bvid/ts_start/end/speaker/text/confidence）
reasoning_unit    推理单元（thesis/premises/conditions/counter_arguments/asset_refs/source_segment_ids）
claim             观点（立场/置信度/有效窗口/证伪条件/evidence_ids/analyst/date）
evidence          证据（id/symbol/market/field/value/unit/currency/period/as_of/source/endpoint/raw_ref）
analysis_framework 分析框架（market/asset_class/strategy/steps_json/必查变量）
reasoning_pattern 交易模式（owner/market/asset_class/horizon/trigger/premise_graph/
                          confirmation/invalidation/action_boundary/source_reasoning_ids/
                          sample_count/win_rate/calibration/regime_tags/status/version）
memory_item       统一记忆（workspace_id/scope/memory_type/subject/market/content_json/
                          source_refs/confidence/status/valid_from/valid_until/version/supersedes_id/
                          write_reason/created_by/reviewed_by）
evaluation_run    评估记录（pattern_id/regime/sample_count/outcome/基线对比/结论）

【私有域 private】(全部带 workspace_id)
user              （id/email/role/invite_code/quota）
portfolio_position（workspace_id/symbol/shares/cost/note）
decision_record   （workspace_id/asset/decision/reason/confidence/falsify/status）
chat_session      （workspace_id/messages_jsonl/tool_trace）
research_note     （workspace_id/export_job...）
audit_log         （who/what/when/私有数据访问/Agent调用/管理员操作）
```

**隔离原则**：公共域（观点/证据/模式/框架）= 所有用户共享只读（这是产品资产）；私有域（持仓/决策/会话/笔记）= workspace_id 严格隔离。所有查询显式传 workspace_id，禁止前端传任意 user_id。

## 4. 施工顺序（Phase 0-3，标注 Vibe 已验证可借鉴）

### Phase 0：数据底座止损（1-2 周）★先解决"逻辑被消磨"
- [ ] 核查 ASR 是否保留完整 JSON（当前可能只存文本？）
- [ ] evidence_extractor：ASR 切语义段 → reasoning_unit 入库（**借鉴 Vibe: transcript_segment 字段标准**）
- [ ] 现有笔记/观点加 evidence_ids，历史回填
- [ ] 验收：任一日报观点可下钻到直播原文时间点

### Phase 1：单人 MVP（2-3 周）
- [ ] FastAPI + React 骨架 + JWT（先单人）
- [ ] 只读研究 API（复用 asset_card/debate_card builder）
- [ ] 研究对话 SSE + 卡片渲染 + 工具轨迹
- [ ] **calc/ 确定性计算包 v1**（借鉴 Vibe: 估值口径函数）
- [ ] **金融研究宪法 v1**（借鉴 Vibe: AGENTS.md 三条不可越线 + 五问 Gate）
- [ ] 接入行情/新闻/公告源（**借鉴 Vibe: 端点注册表 + SourceAdapter**）
- [ ] 验收：能问"今天盯什么"并下钻证据

### Phase 2：内测多用户（+2-3 周）
- [ ] 多用户：邀请码/配额/持仓隔离/审计日志
- [ ] 三 Agent 完整化 + 六因子分析（A股先做，港美先隔离框架）
- [ ] **前提校验**（新事件↔观点：supported/challenged/unrelated/pending）
- [ ] 决策记录 + 复盘闭环（候选→确认状态机）
- [ ] **合规 gate v1**（借鉴 Vibe: 禁买卖建议工程拦截）
- [ ] 订阅提醒：持仓关联事件/观点被挑战/证伪条件触发
- [ ] 验收：内测用户问未覆盖股票，Agent 给出事实/假设/风险/引用（Vibe 的边界——我们的验收必须过这个）

### Phase 3：独立 + 付费准备（后续）
- [ ] **qbs CLI + 自有 worker**：关闭 Hermes 也能跑通全链路（Hermes 变可选 adapter）
- [ ] 分析师模式库 reasoning_pattern + 条件化评估（样本/适用域/基线/时间切分）
- [ ] 学习用户交易逻辑：候选→确认→active（20+ 决策样本后）
- [ ] 港美股深研开放（instrument/日历/框架隔离完成后逐个开）
- [ ] 套餐/导出/OpenAPI/MCP 开放

## 5. 关键风险与对策（v3 新增）

| 风险 | 对策（借鉴来源） |
|---|---|
| LLM 生成幻觉数字 | calc 确定性计算 + 五问 Gate（Vibe） |
| 报告出现违规建议 | 合规 gate 工程拦截（Vibe） |
| 记忆变垃圾堆 | 写入门槛+来源强制+有效期+状态机+定期淘汰（gpt 商量） |
| 分析师模式刻舟求剑 | 模式绑定 market/horizon/regime + 允许过期 + 条件化评估（gpt+Vibe 共识） |
| 学习用户逻辑过度拟合 | 候选→确认→active，绝不自动固化（gpt） |
| 重构破坏现有日报 | evidence_extractor 独立步骤，失败降级不阻塞（老手 v1） |
| 多用户权限漏洞 | workspace_id 显式传参 + 审计日志 + 白名单（老手+gpt 共识） |
| 脱离 Hermes 失败 | 先冻结依赖盘点（HermesAdapter 接口），再逐步夺权（gpt） |
