## 三、方案（5 部分）

### A. tuple_status 映射导出（Mac 只读）
- Mac 导出 `view_id → tuple_status`（聚合口径 **any_ok**：ok 优先 > partial_anchor > template_only，实测与 strict 一致）
- 拉回本地存 `data/view_tuple_status.json`；无关联 view 本地标 `no_ru`

### B. layered_backtest_v2.py（新脚本，分层核心）
- 输入：prediction_events（仅 resolved）+ view_tuple_status.json
- **四层互斥**：ok / partial_anchor / template_only / no_ru（view 不跨层）
- 每层输出：事件级命中率 + **view 级计权命中率**（分母=COUNT(DISTINCT view_id)，V3）+ Wilson CI + 样本量 + 方向分布（bull/bear/risk）+ 窗口分布 + 日期范围
- 总命中率仅作参考行（标注"混合值，禁止引用"），不并入任何层
- error 事件 → coverage 报表（每层行情覆盖率）；skipped → 原因分布
- 命中规则沿用：bullish ret>0 / bearish ret<0 / risk 阈值 0.5(≤3d)/1.0(≤10d)/2.0(>10d)
- 复用 analyst_score_builder.wilson_interval / 计权逻辑（import，不复制）
- 写入 decision.db 新表 `prediction_backtest_layers`（独立前缀，可回滚，不动现有表）

### C. OOS 时间前向验证
- 切分：train ≤ 2026-06-30 / test ≥ 2026-07-01（参考 8-06 基线分界；7 月起下跌市可观测市场环境影响）
- 每层 train/test 命中率 + CI + 样本量对比
- **判定标准**：
  1. ok 层信息含量：test 段 ok vs template_only 命中率差（期望 ok 显著偏离随机且优于/不差于模板层）
  2. 随机基准检验：每层 binomial vs 50%（模板层期望≈随机，若显著偏离 → 模板句被当预测用 = 分层有效证据）
  3. 分层稳定性：train/test 各层排序一致

### D. 报表
- JSON + 人类可读 Markdown → `data/backtest/layered_report_YYYYMMDD.json/.md`
- 含样本量/口径/时间窗口/数据源（skill 交付纪律）

### E. 测试（tests/test_backtest_layers_14v2.py，backtest-validation V1-V7 对齐）
1. 映射正确性：抽样 10 view 人工核对（V1）

3. 分层互斥：view 不跨层
4. 幂等：重跑事件数/唯一键不增（V2）
5. 计权正确性：view 级分母=COUNT(DISTINCT view_id)（V3）
