## 三、方案（融合定稿）

### A. tuple_status 映射导出（Mac 只读）
- 聚合口径 **any_ok**：语义 = "view 内存在至少一个可用 reasoning unit"（**不是整条推理链完整**），
  优先级 `ok > partial_anchor > template_only`，多状态 view 只保留最高层级
- 同时输出 `status_count`（该 view 关联的 ru 数及各自状态计数，供敏感性分析）
- **保留 strict 口径用于敏感性对照**（不用于主报表，仅报告差异=0 的验证结果）
- 拉回本地 `data/view_tuple_status.json`；无关联 view 本地标 `no_ru`

### B. layered_backtest_v2.py（新脚本）
- 输入：prediction_events（resolved）+ view_tuple_status.json
- **五层互斥**（view 不跨层）：ok / partial_anchor / template_only / **no_ru**（纳入主报告但标记
  "无推理链参考层"，不得参与预测能力结论）/ 总参考行（标注"混合值，禁止引用"）
- 每层每方向：事件级 + view 级计权命中率（分母=COUNT(DISTINCT view_id)）+ Wilson CI +
  样本量 + **方向分层（bullish/bearish/risk 分开报，牛熊不对称不掩盖）** + 窗口分布 + 日期范围
- **四分母报表**：resolved / error / skipped / eligible(=resolved+error)；
  **可评估覆盖率 = resolved/(resolved+error)**；error 按窗口/实体/来源/日期分列
- 命中规则沿用：bullish ret>0 / bearish ret<0 / risk 阈值 0.5(≤3d)/1.0(≤10d)/2.0(>10d)
- 复用 analyst_score_builder.wilson_interval / 计权逻辑（import）
- 写入 decision.db 新表 `prediction_backtest_layers`：**唯一键 (run_id, layer, window, horizon, direction)**，
  **事务写入 + run_id 可恢复回滚**（不直接 DROP；run_id = 时间戳）
- min_sample=30：partial_anchor 层若 view 数 < 30 标"样本不足，不下结论"

### C. OOS 时间前向验证（自审修订：数据现实约束）
- **实测修正**：resolved 728 view **全部为 2026 年事件**（2016-2025 老观点行情缺失→error，符合 8-06 归档逻辑）；
  分层分布 template_only 396 / ok 127 / partial_anchor 49 / no_ru 156
- **主切分**：train ≤ 2026-06-30（272 view）/ test ≥ 2026-07-01（456 view），每层每段报告样本量/命中率/Wilson CI；**test 期不得为空**
- **滚动对照（替代 3 段 walk-forward，gpt 意见 2 修订）**：+1 段 expanding 滚动（以 2026-07-15 为界），
  因 ok 127 view / partial_anchor 49 view 不足以支撑 3 段切分（统计功效不足）
- **min_sample=30 自动标注**：view 级 <30 标"样本不足，仅参考"（partial_anchor train 段预期触发）
- 每层每段：命中率 + CI + 与 ok 层的**差值 CI**（效应量）；随机基准 binomial **双侧 5%** vs 50%
- **解读边界（gpt 意见 3，禁止过强结论）**：
  - template_only 层定位 = **弱语义/污染对照层**（resolved 样本中占 54%，主导既有基线，分层价值凸显）
  - "显著偏离 50%" 不能直接证明预测能力（可能标签/样本选择/市场非平稳）
  - 仅当：预注册规则 + 独立 OOS + 多窗口复现 + 效应量显著 → 才允许称预测证据
  - **主结论定位**：ok(127) vs template_only(396) 对比为核心；partial_anchor/no_ru 仅诊断
