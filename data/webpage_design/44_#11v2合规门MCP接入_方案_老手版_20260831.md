## 二、方案（v1.1，输出侧合规门）

### A. compliance_gate.py 加 output_gate（输出检查）

```python
def output_gate(text, source="mcp") -> dict:
    """输出侧合规检查：扫描文本中高风险建议表述。
    返回 {clean: bool, issues: [...], mode: "annotate"|"block", annotated: text}
    模式：
      annotate（默认）——内容是分析师观点整理（资产卡/多空卡/证据包），
        不删原文，尾部追加合规横幅；命中严重系统建议性表述才 block
      block——整段替换为中性说明（仅用于系统自身输出建议的场景）"""
```

- 检查逻辑：复用 HIGH_RISK_PATTERNS 扫描输出文本（输出中出现"买点/卖点/目标价/止盈/止损/建议买入/建议加仓/稳赚"等表述）
- **红线**：分析师观点原文允许含"看好/看空"（观点整理≠建议），output_gate 不拦截观点本身，只对**建议性动作表述**（买点/目标价/建议加仓/稳赚等）触发横幅

### B. 横幅文案（annotate 模式）

```
---
> ⚠️ 合规提示：以上为分析师观点与数据整理，**不构成投资建议**；买卖/仓位决策请自行判断，投资有风险。
```

### C. MCP 接入（qianboshi_mcp.py）

5 个内容型工具返回值统一过 output_gate：
- 命中 issues → 返回文本 + 横幅（annotate）
- 未命中 → 原文直通（零噪音）
- 全链路留痕：output_gate 命中也写 compliance_gate.jsonl（record 加 `gate: "output"` 区分输入/输出侧）

### D. 红队扩展（selfcheck 加输出侧用例）

```python
OUTPUT_REDTEAM_CASES = [
    ("黄金资产卡…买点 3900，建议加仓…", "annotate"),   # 命中建议表述 → 加横幅
    ("半导体多空对照…多空分歧明显…", "clean"),          # 纯观点整理 → 直通
    ("证据包…目标价 1200…", "annotate"),
    ("复盘报告…当时判断正确…", "clean"),
]
```
