## 二、P0：回撤口径修正（v1 bug）

**现状 bug**：`drawdown = 1 - total_cost/Σ(history buy)` = 1-500/1300 = **61.5% 误报**（黄金/创新药已平仓回收资金被算进投入，且 history 缺 159992 买入 989.01）。

**修正（gpt 审核定稿口径）**：
- 命名改 `cost_drawdown`（**成本口径**，非市值峰值回撤，文档/输出明确）
- 单一成本账本：当前持仓成本 = Σ holdings.buy_amount；已平仓 = closed_positions（权威）；history 仅校验**不重复计入**
- `gross_invested = Σ closed_positions.cost + Σ holdings.buy_amount`；`recovered = Σ closed_positions.proceeds`；`net_invested = gross_invested - recovered`
- `cost_drawdown = (net_invested - current_open_cost)/net_invested`；负值=盈利不触发
- **净投入 ≤ 0 → status=unknown + data_quality 标记，不触发违规**（gpt 意见 2，防除零/负基准）
- 缺 proceeds / 部分卖出无法可靠计算 → data_quality 标记，**不硬判**
- 实测修正后：net_invested=(800+989.01+500)-1917.92=371.09；drawdown=-34.7% → 盈利不触发 ✓

**输出 schema 固定**（无动作字段，gpt 意见）：
```json
{"checked_at": "<当前时间ISO>", "portfolio_updated_at": "<portfolio.updated>",
 "current_open_cost": 500.0, "gross_invested": 2289.01, "recovered": 1917.92,
 "net_invested": 371.09, "cost_drawdown": -0.347, "drawdown_status": "profit",
 "theme_ratios": {...}, "violations": [...], "ok": true/false, "data_quality": []}
```
`checked_at` = 检查时刻（原 v1 误用 portfolio.updated）；`portfolio_updated_at` 单独存（gpt 意见 7）。
