## 二、P0 口径修正（方案二）

**v1 bug**：`drawdown = 1 - total_cost/Σ(history buy)` = 1-500/1300 = **61.5% 误报**
（黄金/创新药已平仓回收资金被算进投入，且 history 缺 159992 买入 989.01）

**v2 口径**（gpt 审核定稿）：
- 单一成本账本：gross_invested = Σ closed_positions.cost + Σ holdings.buy_amount（history 仅校验不重复计入）
- recovered = Σ closed_positions.proceeds；net_invested = gross_invested - recovered
- cost_drawdown = (net_invested - current_open_cost)/net_invested；负值=profit 不触发
- net_invested ≤ 0 → unknown + data_quality（防除零）；缺 proceeds → unverifiable + data_quality（不硬判）

**实测修正后**：net_invested=(800+989.01+500)-1917.92=**371.09** → cost_drawdown=**-0.3474** → profit ✓
（真实数据仍有 2 条真实违规：新能源/电池 100% 超 30% + 单标的 027695 100% 超 30%，照常提醒）
